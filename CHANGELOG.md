# Changelog

## [0.1.0] - 2026-06-12

### Changed
- Default value of `expandStrategy` changed from `'click on expanedIcon'` to `'click on item'`.
- Default value of `constLabelWidth` changed from `undefined` to `120`.
- README badges combined into a single "Bundle Size + Gzip Size = 5.2 kB" badge.

## [0.0.2] - 2026-06-10

### Removed
- Removed unused `rootProtection` option (and `RootProtection` type) from `useTree`. It had no effect and has been dropped from the API and documentation.
